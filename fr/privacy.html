Politique de confidentialité

25 novembre 2026

Données sur votre appareil

Votre collection, vos achats avec des pièces du jeu, vos réglages et votre progression sont enregistrés sur votre appareil. Vous pouvez réinitialiser la progression dans les réglages du jeu. Le jeu est sans publicité et vous pouvez jouer sans créer de compte.

TelemetryDeck

Dans la version 1.0 (build 1), les statistiques TelemetryDeck sont désactivées. Le jeu ne transmet aucune statistique de jeu à TelemetryDeck.

Game Center

Si vous vous connectez à Game Center, le jeu transmet à Apple vos réalisations et un score correspondant au nombre de tableaux réunis. Vous pouvez gérer Game Center dans les réglages de votre appareil.

Notifications et liens externes

Avec votre accord, les rappels sont programmés sur votre appareil. Vous pouvez les désactiver dans les réglages iOS. Si vous ouvrez une image externe ou le site d’un musée, votre appareil se connecte au fournisseur et sa politique de confidentialité s’applique.

À propos de cette page

Cette politique est hébergée sur GitHub Pages. Pour toute question générale, utilisez le lien public ci-dessous. Évitez de publier des renseignements personnels.
